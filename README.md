# enterprise-document-assistant

A GenAI-powered document assistant built using Retrieval-Augmented Generation (RAG).

## Features
- Upload PDF documents
- Semantic search using embeddings
- LLM-powered question answering
- Source citations
- Multi-document support

## Tech Stack
- Python
- LangChain
- FAISS
- Gemini/OpenAI
- Streamlit
